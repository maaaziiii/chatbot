chatbot designed to help users with car-related queries using cutting-edge AI and web integration. Here’s a glimpse into what makes this project special:

🔧 Key Features

Intent Recognition: Powered by PyTorch and a custom 1D Convolutional Neural Network (CNN) for accurate pattern matching.
Natural Language Processing: Utilizes NLTK for tokenization, stemming, and bag-of-words techniques.
Web Interface: Seamless Flask backend with a sleek, responsive frontend (HTML/CSS/JS).
Dynamic Responses: Threshold-based reply system ensures high-confidence answers (prob > 0.75).
Luxury UI: Clean design with animations and mobile-first responsiveness.
🛠️ Tech Stack

AI/ML: PyTorch, CNN, NLP (NLTK)
Backend: Flask (Python)
Frontend: HTML5, CSS3, JavaScript
Training: 1000 epochs, custom dataset from intent.json
